# 骰子酒馆 · KCD2 骰子小游戏（网页版原型）

《天国：拯救 2》骰子小游戏的网页复刻原型，单文件、零依赖、手机可直接玩。

**在线试玩：** https://bbx9877.github.io/kcd2-dice/

## 玩法
- 无注册登录，选一位骰子玩家 → 选规则（无徽章 / 徽章局）→ 选徽章 → 选骰子（最多 6 颗，不足自动补普通骰）→ 开局
- 先到该规则档的目标分者胜（1500–8000，按乞丐到皇帝 14 档不同）
- 点骰子锁定得分骰，掷骰只重掷未锁定的骰子；爆点（本回合 0 分）清空本回合得分
- 41 颗真实骰子权重、36 件徽章（锡/银/金 × 13 类效果）、6 位骰子玩家
- 右上角啤酒按钮：饮酒提升"幸运日"触发率（用徽章时 40% × 醉酒程度 的概率不消耗次数）

## 数据来源
骰子权重、徽章、等级底注、目标分等取自游戏本体的数据表（item.xml / dice_badge_subtype.xml / rpg_param.xml 等）。

单个 HTML 文件，内联全部 CSS/JS/数据，无构建步骤、无外部请求，可离线运行。
